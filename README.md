# ARM Cortex-M Programming Examples 🔧

This repository contains **embedded C examples** for ARM Cortex-M microcontrollers, showcasing peripheral initialization, control, and interfacing—ideal for real-world firmware and learning.

---

##  Repository Structure
├── GPIO/ # General Purpose Input/Output examples

├── I2C/ # Inter-Integrated Circuit communication

├── SPI/ # Serial Peripheral Interface communication

├── UART/ # Universal Asynchronous Receiver-Transmitter examples

├── ADC/ # Analog-to-Digital Converter examples

├── LED/ # LED blinking and control examples

├── LCD/ # LCD interfacing (4-bit & 8-bit)

├── Switch/ # Switch handling & debouncing

├── Utilities/ # Common utilities (delay, headers)

└── Startup/ # Microcontroller initialization code
